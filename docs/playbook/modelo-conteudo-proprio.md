# Modelo de conteúdo próprio
Matéria longa de autoria própria, baseada em várias fontes. Definição do usuário ainda em aberto em 31/10/2026; os limites abaixo são a proposta vigente.

Fluxo: tema → dossiê → pauta com ângulo próprio → redação por seções → checagem → originalidade → revisão jurídica preliminar → aprovação humana → publicação.

- Meta inicial: 1.500 a 3.000 palavras.
- Várias fontes independentes; contexto, dados e análise que nenhuma delas traz sozinha.
- Sem paráfrase de uma matéria só e sem trechos longos copiados; citação curta, com aspas e crédito.
- Fontes listadas com link; aviso de uso de IA; data de atualização; histórico de correções; canal de direito de resposta.
- Publicação só com aprovação humana.
