# SINDINFOR: destaques de outubro/2026
TI e software para PMEs, com cinco questões:
1. **Carga tributária do software na Reforma (IBS/CBS).** A folha não gera crédito, então a alíquota efetiva sobe.
2. **Split payment.** Atraso das APIs do Comitê Gestor do IBS pressiona as casas de software e os ERPs.
3. **Pós-eleição.** Continuidade do FNDCT, incentivos a polos tecnológicos e Simples Nacional.
4. **Planos de governo para IA.** Governo Digital e regulação da IA no setor privado.
5. **ERP como ferramenta de sobrevivência.** Dupla vigência tributária e nota fiscal no novo formato.

**Pedido para os próximos meses:** perspectivas do governo Cleitinho em Minas para a indústria de software mineira.

Atenção: no relatório o SindInfor é tratado como Minas Gerais. O perfil no banco ainda diz Brasília/DF; confirmar com o dono.
